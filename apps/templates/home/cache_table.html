Understanding cache hit ratios

These ratios describe cumulative PostgreSQL buffer activity. A lower ratio indicates more buffer misses; it does not measure query latency or the operating system cache.

Compare table and index ratios with workload, table size and recent statistics resets before changing configuration. Missing values mean statistics are unavailable.
